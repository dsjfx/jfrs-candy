# jfrs-candy

jfrs-candy 是一个基于 Vue 3、Vite、TypeScript 和 Pinia 的个人博客 Web 应用。它以简洁现代的方式展示文章内容，同时支持照片墙和个人介绍页面。

## 主要功能

- 首页展示精选内容、最新文章以及文章搜索
- 文章详情页支持目录、标签、分享和点赞/点踩互动
- 图片画廊支持分页浏览和图片预览
- 归档页和关于页便于整理个人内容
- 响应式布局，界面简洁优雅

## 快速开始

安装依赖：

```bash
pnpm install
```

启动开发服务器：

```bash
pnpm dev
```

构建生产版本：

```bash
pnpm build
```
