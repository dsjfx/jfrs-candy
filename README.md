# jCandy

jCandy is a personal blog web app built with Vue 3, Vite, TypeScript, and Pinia. It provides a clean reading experience for articles and includes a photo gallery and personal profile pages.

## Main Features
- Home page with featured content, latest articles, and article search
- Article detail page with table of contents, tags, sharing, and like/dislike reactions
- Photo gallery with pagination and image preview
- Archive and About pages for organizing personal content
- Responsive design with a simple and elegant UI

## Quick Start

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Build for production:

```bash
pnpm build
```
