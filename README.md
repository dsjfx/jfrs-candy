🚀 使用说明

安装依赖

```bash
npm install
```

开发

```bash
npm run dev
```

构建

```bash
npm run build
```

代码检查

```bash
npm run lint              # ESLint 检查
npm run lint:style        # Stylelint 检查
npm run format            # 格式化代码
npm run type-check        # TypeScript 类型检查
```
